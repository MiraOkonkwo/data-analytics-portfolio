FlagThe tier sold as fastest is the least dependable. First Class orders miss their promised date 95.3% of the time. That isn't noise. It's the SLA promising a transit time the fulfillment process cannot deliver.

FINDING 02

It isn't seasonal, it's structural

Plotting the late-delivery rate across 37 consecutive months shows almost no movement: no holiday spike, no gradual fix. The process has run at roughly the same failure rate since 2015.

NoteRange: 51.9%–56.8% across 37 months, tightly banded around the 54.8% mean. That's a process running in a stable, chronic failure state, not an event to route around.

SECTION 05

Recommended actions

No. 1

Re-baseline the expedited SLAs

First Class and Second Class promise transit times the network misses 95.3% and 76.6% of the time, respectively. Reset the "scheduled" days to match what fulfillment can actually hit, using real percentile data instead of the current target.

No. 2

Stop routing the fix through regional teams

Every one of the 23 regions shows the same shipping-mode pattern. A regional or department-level fix will not move the number. This needs a single change to the shipping-mode SLA and carrier capacity, owned centrally.

No. 3

Manage Standard Class for consistency, not speed

Standard Class ships about on schedule on average yet still misses 38% of the time. That's a variance problem, not a bias problem. Track P90 delay alongside the mean, and investigate pick/pack and carrier hand-off consistency.

No. 4

Flag the $2.15M overlap before it ships

18,553 orders were both late and unprofitable. Add a pre-shipment flag that joins shipping mode risk with order margin, so at-risk, low-margin orders get reviewed before they become a late, negative-margin order.
