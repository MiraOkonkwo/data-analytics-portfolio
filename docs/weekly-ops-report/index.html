METHOD

How this replaces the manual version

This is the part that mirrors my actual job: I used to build a report like this by hand in Excel or Google Sheets every week. Here, a Python script (notebooks/01_analysis.py) reads the raw call log, computes every KPI above by week, department, and agent, and writes clean summary tables to outputs/. Next week's report is: drop in the new export, rerun the script, and this dashboard is current again.

The tradeoff is that this version is a static HTML page rebuilt from a CSV snapshot, not a live-connected Power BI or Tableau report sitting on top of a real database. The calculation logic is the same either way, and it's exactly what I'd port into Power BI or a scheduled pipeline if this were plugged into a live system.
