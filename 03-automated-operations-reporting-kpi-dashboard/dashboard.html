METHOD

How this replaces the manual version

This part mirrors my actual job. I used to build a report like this by hand, in Excel or Google Sheets, every week. Here, a Python script does the work. It's called notebooks/01_analysis.py. It reads the raw call log. It computes every KPI above by week, department, and agent. It writes clean summary tables to outputs/. Next week's report is simple: drop in the new export, rerun the script. The dashboard is current again.

There is one tradeoff. This version is a static HTML page, rebuilt from a CSV snapshot. It is not a live Power BI or Tableau report connected to a real database. The calculation logic is the same either way. I would port this same logic into Power BI, or into a scheduled pipeline, if this connected to a live system.
